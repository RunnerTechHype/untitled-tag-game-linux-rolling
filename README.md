# Welcome!
Introducing UTG/Linux Garfield (Rolling release)!!

⚠️ **IMPORTANT ANNOUNCEMENT**: The Rolling release model will be **discontinued on August 31st, 2026** to begin development of UTG/Linux Garfield 14 Pre-alpha (Based on Debian 14 Forky Testing). Development will shift to the stable branch with a point release model similar to standard Debian releases.

# What is UTG/Linux Garfield?
It's a Linux Distribution for untitled tag game players (Based on Debian Sid) with KDE Plasma as main DE. The main installer is Calamares. With the Rolling Release model, it receives the latest packages from Debian Sid with regular snapshot releases.

# Features
- Calamares Installers (with custom slideshow)
- Post-installation script after installation (utg-post-install.sh) (Planned for v14.5+)
- Flathub repository included
- Added Sober (An unofficial Roblox Client for Linux)
- Rolling releases model (Receive latest packages from Debian Sid)
- KDE Plasma 6 (v6.5.1+)
- Breeze Dark theme by default
- Dracut with zstd compression (Planned for next version)
- Snapd blocked by default (Planned for stable version)
- Support for low-end PCs with LXQt (Planned)
- And more

# Desktop Environment (DE)
