# Welcome!
Introducing UTG/Linux Garfield (Rolling release)!!

⚠️ **IMPORTANT ANNOUNCEMENT**: The Rolling release model will be **discontinued on August 31st, 2026** to begin development of UTG/Linux Garfield 14 Pre-alpha (Based on Debian 14 Forky Testing), with Alpha launch scheduled for October 2026.

# What is UTG/Linux Garfield?
It's a Linux Distribution for untitled tag game player's (Based on Debian Sid) with KDE Plasma as main DEs. Main installers is Calamares Installers. With Rolling Release model, which is receive the latest packages from Debian Sid.
